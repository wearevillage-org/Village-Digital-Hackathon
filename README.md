# Village Digital Hackathon

A prototype of the **Village content space**: members propose articles and photos, moderators review them, and approved content appears in one library with credit.

> **Synthetic data only. Nothing here connects to the live Village app or to real member data.**

Built on 10-11 October 2026 by the Village community, for the Village community. 🏳️‍🌈

## Start in 3 steps

1. **Open the project.** Click **Code → Codespaces → Create codespace on main** (nothing to install).
   Prefer your own machine? Clone the repo and install [Node.js](https://nodejs.org/) and [Bun](https://bun.sh/).
2. **Install:** `bun install`
3. **Run in your browser:** `bun start --web`

Stuck? Ask in the hackathon chat. No stupid question.

## The theme

Create a content space in our app: a voice for the community, a moderation workflow that keeps it safe, and one library with three sources (**Village**, **Community**, **External**).

| Priority | What |
|---|---|
| **Must** | Propose content and review it; keep the space safe |
| **Should** | Content from the three sources in one library |
| **Nice** | Recognition of contributors, personalised views and filters |

How you interpret it is up to you.
